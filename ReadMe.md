Lista de Tareas Sencilla

Este proyecto es una aplicación web simple de lista de tareas (To-Do List) construida con HTML y CSS. Permite a los usuarios agregar tareas, marcarlas como completadas y eliminarlas.


Características:

Agregar Tareas: Introduce una nueva tarea en el campo de texto y añádela a la lista.
Marcar como Completada: Haz clic en el checkbox al lado de cada tarea para marcarla como completada.
Eliminar Tareas: Elimina tareas de la lista haciendo clic en el botón "Eliminar".
Contadores: Visualiza el número de tareas totales, completadas y pendientes.

Tecnologías Utilizadas:

*HTML: Estructura y contenido de la página web.
*CSS: Estilos visuales y diseño de la aplicación.
